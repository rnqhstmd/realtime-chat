# 공통 용어 사전

> 도메인을 가리지 않고 프로젝트 전체에서 쓰이는 용어입니다.
> 도메인별 용어는 `context/{도메인}/glossary.md`를 참조하세요.

| 용어 | 설명 |
|------|------|
| Idempotency | 동일 요청/이벤트를 여러 번 처리해도 결과가 한 번 처리한 것과 같도록 보장하는 성질. 중복 이벤트 방지의 핵심 |
| DLQ (Dead Letter Queue) | 정상 처리에 반복 실패한 메시지를 격리 보관하는 큐. 재시도 소진 후 보관 |
| Projection | 이벤트 스트림을 읽어 조회에 최적화된 읽기 모델(테이블/뷰)로 변환·유지하는 것 |
| Snapshot | 특정 시점까지의 상태를 압축 저장한 것. 전체 리플레이 비용을 줄이기 위해 사용 |
| Replay | 저장된 이벤트를 시간순으로 다시 적용하여 상태를 재구성하는 것 |
| Event Sourcing | 상태 자체가 아니라 상태를 바꾼 이벤트의 나열을 진실의 원천(source of truth)으로 저장하는 패턴 |
| Hot Path | 호출 빈도가 높아 성능에 직접 영향을 주는 핵심 경로(쿼리/코드) |
